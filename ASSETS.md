# Assets

Every image and data file the world map is drawn from, and how each one was made. The game uses
no uploaded images, models or audio: everything on the map is drawn in code from the data files
below, with Roblox's own fonts.

Part A of the map upgrade (the full-height framing, zoom levels, camera and land palette) added no
images.

| Asset | File | How it was made | Origin |
|---|---|---|---|
| Map settings and the land palette | `src/StarterPlayer/StarterPlayerScripts/UI/MapConfig.luau` | Hand-authored: framing, zoom levels, camera speeds, border weights and the muted lore colours of each region (the atlas look and the Terrain map mode) | Original |
| Map outlines (regions, sub-territories, Beyond the Wall, the Wall, the Gift, the Stepstones) | The generated block of `src/ReplicatedStorage/Shared/Data/World/MapData.luau` | Generated by `tools/mapgen/generate_map.py`, which traces the reference political map image supplied by the project owner for the earlier map redesign (sea and region colours classified per pixel, cleaned, split into sub-territories around the game's provinces, then vectorised). The reference image is not in the repository | Derived from that reference image. Whether these shapes count as the project's own depends on the rights to the reference image. An independently drawn coastline can replace them: the generator rewrites only that block, and the rest of the game reads the outlines through MapData |
| House palettes, map labels, crest positions, locations (castles, cities, ports, landmarks) | The hand-written parts of `MapData.luau` | Hand-authored | Original (place and house names are from *A Song of Ice and Fire*) |
| House crests | `src/ReplicatedStorage/Shared/Data/World/SigilArt.luau` | Generated by `tools/mapgen/build_sigils.py` from vector shapes drawn in code in `tools/mapgen/sigils/*.py` (with `tools/mapgen/sigil_kit.py`) | Original drawings |
| Location icons | `src/StarterPlayer/StarterPlayerScripts/UI/MapIcons.luau` | Drawn from plain frames in code (castle, house, anchor, tower) | Original |
| Lobby shields | `UI.shield` in `src/StarterPlayer/StarterPlayerScripts/UI/UIComponents.luau` | Procedural, from each house's heraldry colours | Original |
| Fonts | `src/StarterPlayer/StarterPlayerScripts/UI/Theme.luau` | Roblox built-in fonts only (Grenze Gotisch, Merriweather, Source Sans), taken from the engine's own font list | Roblox |
